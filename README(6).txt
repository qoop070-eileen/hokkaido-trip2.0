北海道 6 日遊 Travel Planner PWA 6.9

6.9 收據 OCR 防呆與翻譯升級：
- 保留 PP-OCRv5 優先、Tesseract 備援、語音與 PWA 功能。
- 日本收據維持「日文原文＋繁中對照」；先用內建旅遊/便利商店字典，無法對照時在線狀態再嘗試日文→繁中翻譯。
- 台灣收據品項只顯示單列，不重複原文/中文對照。
- 強化排除合計、總額、小計、付款、消費稅、找零、餘額、回饋等非商品列，避免把收據總額重複算進品項。
- 每個 OCR 品項保留辨識信心；低於門檻會以 ⚠️ 標示，可直接修改或按 × 刪除。
- 新增「品項加總 vs 收據總額」自動驗算：一致顯示 ✅，不一致顯示 ⚠️ 並保留人工修正。
- 日本免稅/退稅仍只在收據有明確「免税 / Tax Free / 免税対象 / 免税額」等文字時判定，不因 8%/10% 稅率自行推測。
- 最終入帳仍以使用者確認的收據實際付款總額為準。

部署：將 index.html、manifest.webmanifest、sw.js、README.txt 覆蓋 GitHub Pages repository 根目錄；icons 不用更動。
