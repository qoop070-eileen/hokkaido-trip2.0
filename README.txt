北海道 6 日遊 Travel Planner PWA 6.6

這版針對實機 Costco / NET 收據測試升級：
- 保留已可使用的語音新增、語音記帳、PP-OCRv5、PWA 功能。
- 台灣收據顯示 NT$；日本收據顯示 ¥，切換收據類型時同步更新。
- Costco / NET / 便利商店等品牌辨識後，忽略品牌上方的照片背景文字，避免把包裝上的文字誤當店家或品項。
- Costco 格式支援「品名 + 下一行商品碼 / 數量 / 單價 / 金額」。
- 支援折扣尾碼 100-T，會以 -100 納入品項加總。
- 排除地址、會員號、機號、序號、商品數小計、折價券數量、停車英文等非商品資料。
- 總金額優先讀取「總金額 / 總計 / 合計 / 應付 / 實付 / 信用卡」等總額列。
- PP-OCRv5 若把品名與價格拆成不同文字框，會利用文字框位置再做配對。
- Service Worker 快取版本升級為 v6.6。

部署方式：
把 index.html、manifest.webmanifest、sw.js、README.txt 四個檔案覆蓋到 GitHub repository qoop070-eileen/hokkaido-trip2.0 的根目錄。
原本 icons 資料夾不用更動。
GitHub Pages 部署完成後，手機 Chrome 重新整理；若仍顯示舊版，可關閉分頁後重新開啟網站再測試。

測試重點：
1. NET 收據：4 個服飾品項，總額 NT$2,576，信用卡。
2. Costco 收據：總額 NT$3,275；品項應包含 1173、716、469、-100、399、289、329，品項加總應為 NT$3,275。
