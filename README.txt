北海道 6 日遊 Travel Planner PWA 6.4

安裝：將 index.html、manifest.webmanifest、sw.js 與原本 icons 資料夾一起部署到 HTTPS 網站（例如 GitHub Pages），Android Chrome 開啟後選「安裝應用程式／加到主畫面」。

6.4 OCR 重點修正：
- 保留目前已可使用的「語音新增」「語音記帳」與 PWA 架構。
- 收據 OCR 改為 PP-OCRv5 優先；瀏覽器不相容時自動切回 Tesseract.js 備援，不會讓整個記帳功能失效。
- PP-OCRv5 使用文字偵測框位置，依收據由上到下、由左到右重建文字列，再交給品項／總額解析。
- 支援台灣繁中、日本日文與英文收據文字；台／日仍可手動指定。
- 顯示辨識引擎與（PP-OCRv5 可取得時）平均辨識信心，低信心不強行猜金額。
- 保留 OCR 原始文字、照片預覽、人工修正、手動輸入與確認後才入帳。
- 第一次使用 PP-OCRv5 需要網路下載瀏覽器 OCR 模型；模型載入失敗會自動使用備援 OCR。

注意：收據請盡量平放、填滿畫面、避免反光與陰影。任何 OCR 都可能因熱感紙褪色、字體、折痕或拍攝角度產生誤判，入帳前請核對總額。
